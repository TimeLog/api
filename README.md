# TimeLog API resources

Public resources for working with the TimeLog APIs. The documentation itself is on the
[TimeLog developer portal](https://timelog.documentationai.com).

## Bruno collections

Ready-to-run collections for [Bruno](https://www.usebruno.com), a free, open-source API client. Every request is
already built and has a test that tells you whether the call worked.

| Collection | Download | Guide |
|---|---|---|
| Transactional API | [timelog-transactional-api.zip](https://github.com/TimeLog/api/releases/latest/download/timelog-transactional-api.zip) | [Transactional: Try it](https://timelog.documentationai.com/transactional/guides/try-it-with-bruno) |
| Reporting API | [timelog-reporting-api.zip](https://github.com/TimeLog/api/releases/latest/download/timelog-reporting-api.zip) | [Reporting: Try it](https://timelog.documentationai.com/reporting/guides/try-it-with-bruno) |

The collections contain no credentials. You enter your TimeLog address and credentials in Bruno's **TimeLog**
environment, and Bruno keeps the secrets on your machine only.

Each version is published as a [release](https://github.com/TimeLog/api/releases); the links above always point to
the latest one.
